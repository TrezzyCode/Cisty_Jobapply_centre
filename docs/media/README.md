# Cisty promotional media

- `cisty-promo-no-music.mp4` — 1920×1080, 30 fps, 27 seconds; no background music, with restrained CC0 interface SFX.
- `cisty-promo-preview.gif` — lightweight silent README preview linked to the full MP4.
- `cisty-promo-poster.png` — static fallback artwork.

The UI imagery is generated by `InternshipAutoApply/promo/capture_demo.py` from an isolated fictional database. It does not read the user's real Cisty profile, Gmail, OAuth token, resume, API key, or company database.

Rebuild the public video from `InternshipAutoApply/promo/`:

```powershell
py -3 promo\capture_demo.py
cd promo
npm run render:no-music
```

The SFX files, licenses, hashes, and source pages are recorded under `InternshipAutoApply/promo/public/audio/sfx/`.
